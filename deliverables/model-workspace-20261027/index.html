功能要求

FR-01 · 题库与槽位同步

用户可绑定已有页面 / 槽位组为题库，或为新题库创建独立页面。题目关联到具体槽位，包含题干、参考素材、期望效果、模型类型、评分维度和标签。槽位的文本及附件变化反映到题库；题库编辑确认保存后写回对应槽位。

空槽位不作为有效题目。附件引用失效时标明缺失，相关题目不能提交；不删除源文件。同步发现双方修改时展示差异，让用户选择保留版本，不静默覆盖。解绑题库保留槽位内容；删除题库索引不等于清空槽位。

FR-02 · 出题能力

用户选择出题模型、目标模型类型、能力维度、难度 / 标签及题目数量，生成结构化题目草稿。草稿包含测试输入、必要参考素材说明及可观察的评分标准，用户逐题编辑、排除重复和确认后保存到题库并同步槽位。

未配置出题 LLM 时引导至配置中心。生成失败保留已生成草稿；重试显示是否会再次请求模型。不能将模型生成的答案直接视为标准答案或有效评分。DeepSeek 在画布生成链路中继续只承担提示词优化，不用于直接生成媒体。

FR-03 · 测评任务与结果集

用户选择题库、题目子集、模型和适用参数，先查看题目数、模型数及计划请求数，再主动启动。任务使用当次固定的题库版本、输入素材与模型配置；运行中修改配置或槽位只影响后续任务。

题目和模型形成结果矩阵。每个单元显示等待、运行、成功、失败、取消或提交状态未知；展示真实文本或媒体、耗时、有效参数、错误信息及模型返回的任务标识。结果按本次测评分组保存，重启后可查看与恢复已确认的异步任务。

失败单元可单独重试，不重复成功单元。已提交但响应丢失的任务标为未知，不自动重提；取消阻止新的请求，已提交任务按服务方支持情况处理并明确展示。结果写回槽位必须由用户选择目标并处理占用冲突。

FR-04 · 最多 14 个模型同时对比

一次对比最多选择 14 个模型，以同一题目行展示多模型结果，支持横向滚动、聚焦、筛选、并排媒体查看和导出。第 15 个选择被阻止，并保留前 14 个选择。不同输出类型分组比较，参数不一致处可见。

14 个模型可加入同一次测评批次；实际请求调度遵守服务方限流和应用资源预算。界面显示排队原因与进度，不把尚未发送的请求显示为运行中。预览按需加载，原始媒体比例保留。

FR-05 · 排行榜与六维能力

提供 LLM、图像、视频能力榜；音频结果可在对应类型下查看。榜单来自可追溯的测评与评分，按模型类型、题库版本和评分口径筛选。每项显示有效样本数、缺失维度、评分方式及更新日期；未评分或缺少有效结果时不生成综合名次。

维度可观察内容适用边界
响应效果对题目要求的理解、执行与输出质量；耗时另列所有模型类型
画面美感构图、色彩、细节、视觉完成度图像、视频
参考效果对给定参考文本、图像或音频的利用程度题目包含参考输入时
保持效果主体、角色、风格或指定约束的一致性题目明确指定保持目标时
运动效果动作连贯性、物理合理性和镜头运动视频
音频效果音质、语音 / 音乐表现及音画配合音频、含音频的视频

六维图对不适用维度显示“不适用”，对未评分维度显示“待评分”，不将两者记成零分。不同适用维度集合不混排一个综合榜。人工评分与自动评判分开标注；自动评判须明确评判模型及其可读取的输入类型。

[Assumption, TBD] 首版采用可编辑的 0–100 分口径，默认等权，允许题库定义维度权重；默认展示本地测评榜。外部榜单来源、自动评判模型与最终评分口径尚未由用户指定，须在配置和榜单中显式说明。

FR-06 · 统一配置中心

管理服务名称、API 地址、认证方式、密钥、模型标识、模型类型、输入 / 输出能力、用途、默认参数、超时及并发限制。一个服务可配置多个模型；用户分别指定画布图像、视频、音频、Agent LLM、出题和测评的默认模型。

保存、连通性检查、能力发现和生成请求分开操作。检查不能伪装为免费的真实生成；不支持的接口契约明确标示。删除仍被默认用途或未完成任务引用的配置时，先提示依赖并让用户调整。已有配置迁入统一目录时保留原有选择与凭据。

内部产品 CLI 在独立合集展示，使用其本地安装、登录、区域、账号与能力配置。CLI 与 API 具有不同配置形式，但可共同出现在按输出类型筛选的模型选择器中。每个任务保留最初选择的来源，失败后不偷偷换来源。

FR-07 · AI 日报

提供每日新闻列表、来源筛选、关键词搜索、原文打开和手动刷新。页面进入时检查更新，显示最近成功抓取时间；有缓存时先显示缓存，失败时保留缓存并提示来源错误。新闻重复链接合并，日期缺失的内容不标为今日最新。

来源支持配置，按原文发布时间排序；摘要区分来源摘要与模型整理。摘要模型请求由用户主动启用。过期、断网、单来源失败和全部来源失败各有可见状态。

共享规则

对象主要状态与规则
题库未绑定 → 已同步 → 有修改 / 冲突 → 已同步；测评使用固定版本
题目草稿生成中 → 待审核 → 已保存；未确认草稿不写入槽位
测评单元等待 → 运行 → 成功 / 失败 / 未知；取消停止尚未提交的单元
评分待评分 → 已评分；保存评分来源、适用维度和口径
模型配置未配置 / 待验证 / 可用 / 验证失败 / 停用；任务固定原配置版本
新闻来源未加载 / 更新中 / 已更新 / 部分失败 / 离线缓存

凭据不进入题库、结果导出、错误信息和新闻缓存。关闭模型页面不会丢弃已保存的测评结果；运行请求和媒体预览分别管理。请求计费、远端取消和重试可否保证不重复均以具体服务能力为准，在启动预览或恢复任务时可见。
