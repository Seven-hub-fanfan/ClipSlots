# 侧边 Agent 应用市场

目标版本：v2.17.102。入口：侧边 Agent 底部「使用应用拓展 Agent 能力」，或输入框「＋ → 应用市场」。

市场在侧栏内部打开，可以返回原对话。对话视图保留在市场背后，返回时保留欢迎动画与滚动状态。包含最新上线、官方能力、创作用例、本地技能和效率工具；支持搜索、类别筛选和详情浏览。

五类创作用例覆盖品牌设计、影视分镜、电商广告、互动游戏和网页应用设计。详情填写主题、补充要求与比例，可添加本轮资料；「在对话中试用」把完整指令追加到草稿，由用户编辑后发送。游戏与网页类交付设计和实现需求，实际工程执行取决于已接入工具。

本地技能来自现有异步扫描器。「添加到 Agent」更新真实授权集合；「引用到本轮对话」读取本地 SKILL.md，仍遵守最多四项、单项不超过 64 KiB 的限制。停用会移除授权。

效率工具详情打开现有插件管理，保留真实安装、下载和运行流程。独立应用安装与技能授权分别处理。

画布 MCP 详情打开现有项目连接界面，创建绑定当前项目与会话的 30 分钟本地连接。只读视图创建只读连接，不能通过市场升级权限；写入仍需原生确认与版本检查。

界面使用原生 SwiftUI 图形封面与中性名称，支持深浅、简洁和多彩主题。没有导入参考产品的商标、账号图片或远端素材。

研究证据和未核验范围见 [Agent 能力与应用市场调研](Agent能力与应用市场调研.md)。云端 MCP 不带授权返回 401，因此尚未获得其具体工具清单。本地 MCP 的真实工具与写入行为另做隔离验证。
