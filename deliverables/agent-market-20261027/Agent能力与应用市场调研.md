# Agent 能力、画布 MCP 与应用市场调研

对照版本：本机安装的 TapNow 0.4.155。核验日期：2026-10-27。当前 ClipSlots 基线为已发布、已安装的 v2.17.101。

## 应用市场

**界面实测**：市场首页包含“最新上线”横向展示区、“官方技能”横向卡片区。当前窗口为 1440 × 949；展示区采用圆角封面卡，技能卡采用深色背景、柔和边框、图标与简短说明。原始截图保留在隔离研究目录，不向产品导入账号信息或参考产品品牌。

原生窗口证据：`ev_34eceee2a3723aee2d618cfbb0f34d36242485d9515114ac407d170670587fe5`，目标窗口 70496、进程 18393；目标可执行文件 SHA-256 为 `7bf877f88d919b320c3fb2e446b7c5113bbf05bf86301dc6b031238a630e3def`。

**源码核验**：市场支持“全部 / 应用 / 官方技能”及业务分类，搜索应用或用例；包含品牌设计、影视创意、电商广告、互动游戏、网页应用等场景。应用详情提供能做什么、所需资料、工作方式、产出、适用边界、后续提示词和已连接工具。入口状态区分“添加到 Agent”“添加中”“在对话中试用”和不可用状态。

**任务流程**：部分用例进入素材表单，支持图片、视频、产品信息、品牌信息、比例、时长等输入。源码存在必填校验及上传失败处理；创建失败会尝试清理本轮创建的画布。此结论来自静态控制流，本次没有创建远端项目、上传素材或执行付费生成。

市场接口在 `vendor-pkg-agent-DqI4Ylok.js` 中声明：`/api/bff/app-store/catalog`、`/api/bff/app-store/items/{kind}/{name}`。插件安装与技能启用使用不同接口：`/api/agent-gateway/v1/plugins/{name}/installation` 和 `/api/agent-gateway/v1/skills/{name}/status`。因此“安装应用”“启用技能”“填入用例提示词”需要分别实现，不能共用一个装饰性状态。

## Agent 运行能力

**源码核验**：客户端声明创建会话、继续运行、运行事件流、确认交互、问答、取消、运行中补充指令、活动运行查询、会话分支、插件、连接器、技能与共享页面接口。事件流解析包含 `tool_event`、`client_tool_request`、`subagent_event`、`user_steer`；其中 `show_previs` 保留 MCP 运行身份与事件序号。

前端工具注册器绑定 `client_instance_id`、运行身份及提交时的工具声明；工具卸载、定义改变、运行取消或过期时拒绝继续执行。注册器源码限制 32 个前端工具，参数声明 16 KiB、提交声明 64 KiB、返回结果 64 KiB，并按运行和调用身份复用执行结果。这是当前发货代码中的约束，不代表本次实测了全部云端行为。

## 画布 MCP

**源码核验**：画布具有连接其他 Agent 的入口、复制安装提示词、手动配置提示词和桌面应用打开失败后的网页回退。提示词携带项目身份；连接器按地区和语言控制展示。

客户端声明 Claude、ChatGPT、WorkBuddy、QwenWork 和一个不展示的备用条目；Claude Code 与 Codex 作为桌面配套打开方式。条目存在于代码与实际默认展示是不同事实。

生产 MCP 地址为：

- 全球：`https://mcp.tapnow.ai/api/agent-gateway/mcp/general/mcp`
- 中国：`https://mcp.tapnow.media/api/agent-gateway/mcp/general/mcp`

**协议实测**：向全球地址发送不带凭据的 `initialize` 请求返回 HTTP 401，`WWW-Authenticate` 声明 `mcp.tools.invoke mcp.tools.read` 及 OAuth 受保护资源元数据。本次未发送授权信息、未调用任何 MCP 工具。云端的具体工具清单、账号可用范围和真实生成行为仍未核验。

官方文档链接已从发货代码定位到 `/docs/mcp/use-tapnow-in-other-agents`、`/docs/mcp/add-a-custom-connector`、`/docs/mcp/add-through-an-official-plugin`；网页读取只获得客户端外壳，未把外壳视为文档正文或能力证据。

## ClipSlots 接入位置

调研时的 v2.17.101 基线中，ClipSlots 的侧栏“使用应用拓展 Agent 能力”只打开本地 Skill 选择器。已有独立插件市场、Skill 扫描与启用、个人工作流库、本轮技能引用、模型配置中心及本地画布 MCP，可复用这些实际能力。v2.17.102 的具体实现见 [侧栏市场说明](README.md)。

本地画布操作层包含 3 个实时读取工具和 12 个修改或生成工具，覆盖节点、参数、位置、连线、编组、布局、撤销、重做及生成。另有快照分页读取、槽位工具、产物读取和变更预览工具。只读模式只公开读取能力；外部连接使用与当前项目绑定的短期连接，修改遵守原生确认及版本检查。

实现应将应用市场放入侧栏内部，保留原有草稿、附件、技能引用与当前会话；市场可返回对话。技能添加必须改变真实启用集合，用例必须填入草稿或引用真实技能，画布 MCP 必须打开现有项目连接流程。配置不完整的生成能力需要显示真实条件，不能标为已连接或生成成功。
