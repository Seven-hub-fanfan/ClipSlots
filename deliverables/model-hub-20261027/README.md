## 配置与调用

1. 在「模型 → 配置中心 → 服务连接」设置服务地址、认证、超时与共享并发；密钥保存在 macOS Keychain。可配置只读 GET 发现地址，也可手动输入模型标识。
2. 在「模型目录」搜索模型并接入，绑定服务、填写真实上游模型 ID 和接口协议。目录使用展示别名，调用时以实际服务接受的模型标识为准；原始目录绑定、参数和已保存配置保持完整。
3. 在「用途路由」分别设置 Agent LLM、出题 LLM、画布文本润色、图像、视频、语音、音乐和音效的默认模型。出题路由服务于测评题库。
4. 在画布节点选择「API」，使用默认路由或指定已接入模型。文本节点可指定润色模型；媒体节点传递提示词、图像/视频/音频参考、首尾帧和适用参数。内部产品 CLI 继续在独立合集配置。

支持 Chat Completions、OpenAI Responses、Anthropic Messages、Gemini generateContent、图像生成、同步媒体 JSON、异步媒体任务和二进制语音。服务字段不同的接口需要显式配置输入与输出映射；必需参考缺失、参数越界或输入映射不完整时阻止提交。

多个模型共享同一服务的并发额度，服务与默认路由切换影响后续请求。已提交任务保留原地址、模型和密钥身份进行查询；未知提交结果不会自动重提。现有题库、结果集和新闻数据兼容，测评继续支持最多 14 模型。DeepSeek 在画布文本润色中仍仅承担 prompt 优化。
