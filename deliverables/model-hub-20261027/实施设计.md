# ClipSlots 模型配置中枢实施设计

需求：将 LLM、图像、视频、音频的完整配置表整理进模型配置中心，并集中管理画布节点和 Agent 的调用。模型目录与用户可见文案使用中性名称，原始目录身份用于内部匹配。

## 已确认的输入

- 内置目录 119 项：17 LLM、31 图像、57 视频、14 音频；155 个媒体生成变体。中性导出保留参数与变体，原始来源记录保留在内部核验资料中。
- 静态目录包含全部隐藏模型，不代表用户账号实时开放的模型；公开目录采用展示别名，接入时须填写实际服务接受的上游标识。
- CC Switch 官方文档支持服务共享、模型映射、路由切换和只读模型发现。这些机制用于 ClipSlots 内部节点调度。
- 本次更新基于 v2.17.100，在独立工作树中处理展示脱敏，合并时保留已有的未提交导航修改。

## 配置中心

保留「API 模型 / 内部产品 CLI」合集。API 合集中使用「模型目录 / 已接入 / 服务连接 / 用途路由」四个页面。

模型目录默认展示全部 119 项，支持类型、服务路由、名称与目录别名搜索。每行显示中性名称与别名、服务路由、支持模式、状态和接入动作；详情保留所有参考输入范围、时长、分辨率、选项和默认参数。原始身份及配置不受展示别名影响。窄窗口只显示必要列，完整配置在详情。

服务连接集中设置地址、认证方式、超时、并发和显式模型发现地址；密钥存 Keychain。模型绑定共享连接，配置真实上游标识、请求协议和模型特定参数。修改服务连接后下一次调用获得新快照；未完成任务的查询身份保持不变。

已接入模型支持编辑、复制、停用、移除与用途标记；默认用途或活动任务引用仍受保护。支持只读 GET 模型发现 / 连通状态，不能通过测试连接发起付费生成。发现失败保留手动标识输入。

用途路由覆盖 Agent LLM、出题 LLM、画布文本润色、图像、视频、语音、音乐和音效。现有 canvasAudio 配置仍能作为旧数据回退。文本润色保持 DeepSeek 仅优化 prompt 的业务边界。默认路由可切换，节点可显式覆盖。内部 CLI 原有数据与发现逻辑保留。

## 调用层

新增兼容字段使用 optional 或显式缺省解码；现有模型、题库、结果集和新闻数据保持可读。目录作为只读 bundled resource，启动不为了填充目录写入业务数据。

已有 Chat Completions、Images Generations、异步媒体契约继续可用。根据实际端点增加原生 Gemini、Anthropic / Responses 文本协议、同步 JSON 媒体 / 二进制音频以及可配置输入与输出映射。复杂云服务使用用户显式契约；不猜测服务字段或私有路由。

媒体输入需支持图像、视频和音频，并保留类型与参考角色。请求准备时验证目录变体与实际契约；没有相应输入映射时阻止提交。节点的比例、时长、分辨率、音频、歌词和声音参数进入调用快照。目录 UI 默认值与请求 wire 字段分离，避免直接发送错误的 camelCase 配置。

调度复用既有任务快照、独立存储锁、14 模型评测边界和并发控制。共享服务的并发限制在模型间累计。Agent / 画布 / 测评尽可能使用同一配置解析与协议转换。POST 提交未知不自动重提，不静默更换厂商；已确认任务 ID 继续原任务查询。
