# ClipSlots v2.11.8

macOS 剪贴板槽位管理工具。本版为 v2.11.8 第七轮修复（基于用户录屏反馈），tag 已 force 更新。

## 本轮（第七轮）修复

### 1. 点「+N 点击加载」后第一张图片变灰 —— 参考卡机制整套删除

- 录屏取证（逐帧亮度量化）：点击灰卡后 0.05s，最左侧那张卡的同一像素区平均亮度 **111.8 → 61.8**，比值 0.55，即约 **45% 黑遮罩**，并一直保持；模板匹配确认它与点击前的第 1 张是同一张图（NCC 0.987）。
- 这层遮罩是三轮加的「参考卡」：翻页重叠一张、给它打 40% 黑，用来当"我翻到哪了"的锚点。四轮把卡叠层级反成"第 1 张在最顶层"之后，这张灰卡正好落在**视觉最显眼的位置**，观感就是"点一下第一张图就废了"。
- 按用户要求**直接删除**：`CardWindow.referenceSlot`、`CanvasFanGeometry.referenceDimOpacity`、`arrivedBackward` 全部移除，卡片渲染不再有任何遮罩 / 降 opacity。牌面一律全亮。

### 2. 翻页后出现两张完全相同的图片 —— 窗口改为固定栅格分页

- 根因不是"下标算重复了"（同一帧的窗口本就是连续区间），而是**末页保持满窗**这条旧规则：起点被夹到 `total - cap`。录屏那个节点「入参文件 7」、同屏 5 张，点「+2」时起点 5 被夹回 2 → 新页 `[2,7)` 与旧页 `[0,5)` **重叠 3 张**，屏幕上就是"刚才看过的图又来了一遍"。叠加参考卡的重叠一张（步长 `count-1`），重复更严重。
- 现在窗口按**固定栅格**分页：`[0,cap) [cap,2cap) …`，步长 = 整页容量，末页允许不满。
  - 总 7 张、同屏 5 张：第一页第 1~5 张 + 灰卡「+2」→ 点「+2」**只显示第 6、7 张**（正好是灰卡上写的那个 2），零重叠；点 ‹ 原样回到第一页。
- `CanvasFanWindowState.clamp` / `startRevealing` 同步改成栅格对齐（登记处里的历史起点、拖入新附件后的"露出新增那张"也都落在栅格上），避免两处各算一套导致半页错位。
- 顺带修掉一个**渲染层**的重复隐患：牌面视图原来以"位置下标"为 SwiftUI id，翻页时视图被复用，`CanvasAttachmentPreviewImage` 里的 `@State image` 留在原位；而它的异步回调闭包捕获的是**调用那一刻的 self 快照**，迟到的旧回调会把上一张图写进已经换了内容的卡片。现在 id 编入内容身份（附件 UUID），并额外记 `shownId` —— 图和当前附件对不上就不上屏。

### 3. smoke 断言（用户指定的第 4 条）

- `CardWindow.windowIndices` / `indicesAreSane`：把"窗口摊开是哪几个下标"显式暴露，逐页断言**严格递增、无重复、不越界**。
- 全组合扫描：总数 0~14 × 容量 1~6 × 起点 −3~16，共 2000+ 个窗口，全部校验起点落在栅格、`count = min(cap, 剩余)`、`+N` 的 N 口径。
- **划分断言**：从第一页一路翻到底，把每页下标拼起来必须恰好等于 `0..<total`（每张卡出现且仅出现一次，顺序不变）—— 这条直接钉死"两张一模一样的图"。
- 录屏那一幕的专项用例：`total=7 cap=5` 点「+2」→ `[5,6]`；`total=5 cap=3` 点「+2」→ `[3,4]`，再 ‹ → `[0,1,2]`。

## 前六轮修复（本 tag 累计内容）

- **顺序与窗口跨重建存活**：附件顺序绑定持久化数组下标；翻页窗口存进 `CanvasFanWindowRegistry`，右键 / 切页往返不再打回第一页；当前组写附件后 bump `canvasSlotRevision` 立即刷新。
- **`+N` 点击独占手势**：命中层 `.highPriorityGesture`，点 `+N` 只翻页，不选中、不重建、不弹「入参文件」导入面板。
- **`+N` 灰卡沉到牌面之下**，文案移到实际露出的楔形重心（0.68, 0.36），hover 提浓 0.5 → 0.72。
- **hover 维持区**：节点本体 + 扇形包围盒 + 左右外扩 30pt，离开 200ms 延迟，鼠标去点箭头不再让扇形消失。
- **卡片堆叠**：`zIndex = n - 1 - i`，第 1 张最左且视觉最顶层。
- **缩放不再抖**：排版缩放量化到几何阶梯 + 迟滞 + 落定延时。
- **非图像入参也成卡**：`.mp3` / `.md` / `.command` 正常出现，单击用默认程序打开。
