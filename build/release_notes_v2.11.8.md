## ClipSlots v2.11.8（画布：字号精确恒定 / 文本节点防重叠 / 只留扇形）

> 本 tag 已重打包：指向 commit `4bbf385`，替换了首次发布的 `ec857e2`。

### 1. 缩放时卡片文字的屏幕字号「精确」恒定
- 反向补偿系数从 `min(1, layoutZoom / zoom)` 改成**精确逆比** `layoutZoom / zoom`。
  旧写法在**缩小**过程里必然失效：手势期间 `layoutZoom` 冻结在高档位、`zoom` 一路变小，
  需要的补偿是 **> 1**，却被 `min(1, …)` 夹成 1，于是文字跟着画布一起缩，直到手势结束才「跳」回来。
- 牌面卡（扇形展开的卡片）自己还挂着 hover 的 `scaleEffect(layout.scale)`，
  新增按卡补偿 `textCounter / layout.scale`，抵掉**两层**缩放。
- 取消最小字号兜底与任何非线性/夹取，字号不再随缩放"走档"。
- 节点/卡片视觉尺寸 < 40pt 时**整块文字**一起隐藏，不再逐行判定（避免半截字）。

### 2. 文本节点纵向不再重叠 / 跳变
- 新增纯函数 `CanvasCardLayout.textNodePlan(...)`，文本节点改用 `GeometryReader` 拿**实际**可用高度排版。
- 让位优先级：保住文本输入框 → 高度不够先砍「入参文件」行 → 再不够整体不写字。
- 数学不变量：`路径行 + 文本框 + 入参文件行 + 行距 ≤ 容器高度`，且同一形态内容器变高时文本框只能变高（排除回弹）。

### 3. 删除「水平轮播」「交替叠放」两种展开样式
- 渲染分支、切换按钮、右键子菜单、`CanvasStore` 的切换 API 全部删除，只留扇形（左右翻页箭头保留）。
- 兼容：老画布 JSON 里的 `"carousel"` / `"stackedScatter"` 及任何非法值，解码时迁移为 `fanOut`（不抛错、不丢画布）。

### 验证
- `swift build` 通过；零依赖 smoke：**通过 44539，失败 0**。
- 离屏 CoreText 光栅化实测：25% / 50% / 100% / 200% 四档标题墨迹高度 **均 24px，极差 0px**；
  缩小/放大手势中途（`layoutZoom` 冻结）同样 0px；把公式换回旧的 `min(1, …)` 作为对照，极差 20px（说明该测量能抓住老 bug）。
- 真机截图 + Vision OCR：多个真实缩放档下标题墨迹高度恒为 17px（极差 0px）；文本节点「文本框下沿 → 入参文件行顶部」间隙为正（无重叠）。
