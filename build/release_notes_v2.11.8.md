# ClipSlots v2.11.8

macOS 剪贴板槽位管理工具。本版为 v2.11.8 第六轮修复（基于用户录屏反馈），tag 已 force 更新。

## 本轮（第六轮）修复

### 1. 右键 / 切页后卡叠顺序与翻页窗口紊乱

- **顺序的唯一真相是持久化数组下标**：新增 Kit 纯函数 `CanvasSlotOrder`，明确渲染顺序 = `SlotContent.attachments` 的数组下标，渲染层不再有任何 `sorted` / `reversed`。不用 `createdAt` 排序：首位有语义（缩略图 / 圆盘 / 「设为入参」取的就是首位），按时间排会把「设为入参」和手动排序的结果直接抹掉。新附件一律 append 到尾部。
- **翻页窗口不再活在 `@State` 里**：`windowStart` 原本是 `@State`，右键弹菜单、切到编辑页再切回来都会让节点子树重建、起点被打回 0 —— 用户看到的「新图片从第 1 张变成第 2 张、旧卡片翻到第 1 张」主要就是这个。现在窗口起点存进 `CanvasFanWindowRegistry`（按 `节点id|风格` 记，普通引用类型、不是 `@Published`，鼠标级别的翻页不会触发全画布重排），`.onAppear` 从登记处恢复。
- **附件数量变化不再无条件回第一页**：改用 `CanvasFanWindowState.startAfterCountChange` —— 变多时把新增的最后一张露出来，变少时只做钳制，不跳回开头。
- **当前组写附件后立刻刷新**：`writeCanvasSlotAttachments` 的「当前组」分支此前只 `setAttachments` 不 bump `canvasSlotRevision`，画布节点要等下一次重建才补读数据，于是「右键 / 切页之后顺序才突然变了」。现在两个分支都 bump。

### 2. 「+N 点击加载」点击后弹出导入文件侧边栏

- 根因是**手势优先级**：命中层用的是普通 `.gesture(DragGesture)`，与祖先 `CanvasWorkspaceView.nodeLayer` 上的 `onTapGesture { canvas.select(...) }` 同时参与识别。一次点击既翻了页又改了 `selectedNodeIds`（@Published）→ 节点子树重建 → `isHovering` / `windowStart` 被打回初值 → 扇形当场收拢，而收拢态右下角那颗 `+`（直通「入参文件」面板）正好落在刚点的位置，下一下就点进了导入面板。
- 命中层改为 `.highPriorityGesture`，先于祖先吃掉这次点击：不选中、不重建、扇形不收拢，`+N` 只做 `pageForward()`。
- 选中不能就这么丢：在「非 +N」分支显式调 `onActivateNode()` 补回选中（含 shift 累加）。**唯独点 `+N` 不选中** —— 翻页是纯浏览动作，没理由顺手触发一轮全局重绘。
- `+N` 只在**展开态**认账。收拢态这张灰卡一个像素都看不见，「点到看不见的东西然后页面自己翻了」是意外，不是功能。
- `+N` 的数字 = 总数 − 窗口尾部下标；≤5 张附件不显示 `+N`；翻页仍然保留 1 张参考卡（步长 = 当前页张数 − 1）。

## 上一轮（第五轮）修复

### 1. 「+N 点击加载」灰卡沉到牌面之下
- 此前为了让灰卡能点，给它设了 `.zIndex(350)`，结果它浮在所有内容卡之上，右侧的图片 / 音频卡被半透明灰蒙层盖住 —— 这是错的修法。
- 现在灰卡改成**最底层的纯展示层**（`.zIndex(-1)` + `.allowsHitTesting(false)`）：内容卡从左到右层级递减（第 1 张最高），`+N` 排在最后、最低，只从右边缘露出一块楔形告诉用户「后面还有」。
- 点击不再依赖它自己是不是 Button：命中交给整叠共用的透明命中层，命中第 6 格 → `pageForward()`。露出面积实测约 2085pt²（单卡面积的 17%），且全部落在右半边，够点。
- 沉到底之后居中的文案会被左邻卡完全遮住，只剩描边。新增 `overflowLabelAnchor`（0.68, 0.36），把「+N / 点击加载」搬到实际露出的那块楔形重心上；hover 压在楔形上时不透明度提浓（0.52 → 0.72）作为可点反馈。

### 2. 扇形展开态的 hover 热区（鼠标一偏就收缩）
- 根因：原来只有节点本体的 `.onHover`，鼠标越出节点边框一帧就收缩；而最外侧卡片距节点边框只剩约 11pt、左箭头圆心离左边缘仅 10pt，往箭头一带就过冲出界，扇形和箭头一起消失。
- 新增 Kit 纯函数 `CanvasNodeHover`：`holdRect` = 节点本体 + 扇形展开后的完整包围盒，左右至少再外扩 30pt，把顶部功能图标栏与左右箭头一起圈进同一个维持区。
- **进入严、维持宽**：只有落在节点本体内才会触发展开；已展开的节点只要光标仍在维持环内就保持。离开加 200ms 延迟。

## 前四轮修复（本 tag 累计内容）

- **卡片堆叠顺序**：`zIndex = n - 1 - i`，第 1 张在最左侧且视觉最顶层（右底左顶）；命中优先级与 `+` 角标自动跟随。
- **缩放时文字不再乱动**：排版缩放量化到几何阶梯（公比 ≈1.26）+ 迟滞 1.18 + 落定延时 0.32s；禁掉画布文字的 `allowsTightening` / `minimumScaleFactor`。
- **非图像入参文件也会成卡**：`.mp3` / `.md` / `.command` 不再凭空消失；单击用默认程序打开，气泡新增「打开」「删除」。
- **超过 5 张的翻页**：同屏 5 张牌面 + 第 6 位灰色 `+N` 卡 + 左右箭头，翻页永远保留参考卡。
- **附件删除后面板立即刷新**：低频 `@Published canvasSlotRevision`。
