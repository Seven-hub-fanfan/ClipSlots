# ClipSlots v2.11.8

macOS 剪贴板槽位管理工具。本版为 v2.11.8 第五轮修复（基于用户截图 + 录屏反馈），tag 已 force 更新。

## 本轮（第五轮）修复

### 1. 「+N 点击加载」灰卡沉到牌面之下
- 此前为了让灰卡能点，给它设了 `.zIndex(350)`，结果它浮在所有内容卡之上，右侧的图片 / 音频卡被半透明灰蒙层盖住 —— 这是错的修法。
- 现在灰卡改成**最底层的纯展示层**（`.zIndex(-1)` + `.allowsHitTesting(false)`）：内容卡从左到右层级递减（第 1 张最高），`+N` 排在最后、最低，只从右边缘露出一块楔形告诉用户「后面还有」。
- 点击不再依赖它自己是不是 Button：命中交给整叠共用的透明命中层，命中第 6 格 → `pageForward()`。露出面积实测约 2085pt²（单卡面积的 17%），且全部落在右半边，够点。
- 沉到底之后居中的文案会被左邻卡完全遮住，只剩描边。新增 `overflowLabelAnchor`（0.68, 0.36），把「+N / 点击加载」搬到实际露出的那块楔形重心上；hover 压在楔形上时不透明度提浓（0.52 → 0.72）作为可点反馈。

### 2. 扇形展开态的 hover 热区（鼠标一偏就收缩）
- 根因：原来只有节点本体的 `.onHover`，鼠标越出节点边框一帧就收缩；而最外侧卡片距节点边框只剩约 11pt、左箭头圆心离左边缘仅 10pt，往箭头一带就过冲出界，扇形和箭头一起消失。
- 新增 Kit 纯函数 `CanvasNodeHover`：`holdRect` = 节点本体 + 扇形展开后的完整包围盒（`expandedHalfWidth` 枚举静息与各 hover 态卡片多边形顶点求并集），左右至少再外扩 30pt，把顶部功能图标栏与左右箭头一起圈进同一个维持区。
- **进入严、维持宽**：只有落在节点本体内才会触发展开，路过维持环不会误展开；已展开的节点只要光标仍在维持环内就保持。
- 离开加 **200ms 延迟**（`leaveDelay = 0.2`），快速穿过卡片缝隙 / 边界抖一下不会闪一下收拢。
- 箭头整体向内收 6pt（`arrowLaneInset`），减少贴边过冲。
- 顶部 action bar / 风格切换 / 扇形展开全部改看同一个 `hoverActive = 本体 hover || 维持态`，三者不会再各自判定、互相打断。

## 上一轮（第四轮）修复

### 卡片堆叠顺序：左底右顶 → 右底左顶
- 此前扇形/轮播的静息层级是 `zIndex = i`，**下标越大越靠前**，视觉上最右边那张（内容顺序里的最后一张）压在所有卡片之上，第 1 张被埋在最底下。
- 现在改为 `zIndex = n - 1 - i`：**第 1 张卡片在最左侧且在视觉最顶层**，后续卡片依次向右延伸、层级递减，最后一张在最后方。
- 顺序本身是有语义的（附件列表首位 = 缩略图 / 圆盘 / 「设为入参」取的那一张），首位那张不该被压在最下面。
- 连带自动跟着反转的两处：命中优先级（`hitTest` 按 zIndex 从高到低，现在点重叠区拿到的是靠左那张，与视觉遮挡一致）、收拢态右下角 `+` 角标（挂在 zIndex 最大那张上，不会被卡片压住变成死按钮）。
- **位置与角度刻意不动**：第 1 张本来就在最左且左倾，扇形张开方向（左→右）与「第 1 张在最左」本来就一致；若把角度一起取反会变成「卡片待在左边却向右倾」，相邻卡互相穿插，观感是散落而不是一叠。
- 轮播态同步改成同一层级方向 —— 它平时不重叠看不出层级，但 hover 放大 1.08 的瞬间会短暂相交，两种风格方向一致才不会在切换时出现「前后关系突然反过来」。

## 前三轮修复（本 tag 累计内容）

### 1. 缩放时文字不再乱动（彻底版）
- 排版缩放**量化到几何阶梯**（公比 ≈1.26）+ **迟滞 1.18** + 落定延时 0.32s，同一档位内的滚轮微调一次都不重排。
- 禁掉所有画布文字的 `allowsTightening` / `minimumScaleFactor`（`canvasStableText()`）。

### 2. 非图像入参文件也会成卡 + 点击可用默认程序打开
- 全部附件都成卡（此前 `.mp3` / `.md` / `.command` 凭空消失）；非图像卡片按类型渲染深灰卡 + SF Symbol + 文件名最多 2 行。
- 面板中单击文件名 / 缩略图 → `NSWorkspace` 用默认程序打开；卡片气泡新增「打开」「删除」。

### 3. 超过 5 张的翻页交互（+N 灰卡 / 左右箭头 / 参考卡）
- 同屏最多 5 张牌面，第 6 位是灰色半透明 `+N` 翻页卡；左右箭头翻页，到末尾回到开头。
- **永远保留参考卡**：翻页步长 = 张数 − 1，相邻两页始终有交集，绝不整页替换。
- 删除被下游引用的节点弹 Alert 确认；卡片内单张入参文件删除不弹确认、不影响节点。

### 4. 附件删除后面板立即刷新
- 新增低频 `@Published canvasSlotRevision`（只在画布跨组写时 bump），修刷新且不退回整树重绘。
