## ClipSlots v2.10.85

### 修复：悬停预览显示 macOS 文件图标而非真实图片内容

从 Finder 复制一个图片文件时，剪贴板内容是 `public.file-url` + `com.apple.icns`，后者是 1024px 的**通用文档图标**。由于 `com.apple.icns` 属于合法图片类型，`hasImage` 为真，所有预览路径都优先走「内联图片」分支，把 Finder 图标当成内容渲染，真正的文件像素反而没人读——这就是环形悬停预览显示 PNG 文档图标的根因（与 v2.10.84 的 PERF-4 下采样无关，新旧两条解码路径都会画出这张图标）。

- 新增「仅图标」剪贴板类型判定（icns 系列）；icns 仍属图片类型，真正粘贴 `.icns` 数据时行为不变。
- 内联图片「只有文件图标」且存在 file-url 时，预览改走文件路径：图片文件通过 ImageIO 下采样（长边 ≤ 2048 / 网格 512）显示**真实像素**。
- 非图片文件（PDF / 压缩包等）保留原 Finder 图标渲染，其图标常自带内容缩览，信息量不降级。
- 性能不回退：v2.10.84 的下采样策略完整保留，仍不做原图尺寸解码。

验证：`swift build` 通过；smoke 测试 33 项全绿；DMG 打包校验通过、装机运行正常。
