## ClipSlots v2.11.18

### 图像节点可以选模型、选尺寸了

上一版接上 Crate CLI 能真出图，但模型写死 `seedream45`、比例写死 `1:1` —— 参数栏只是两行只读文字，也就是"能生图，但只能生一种图"。这一版把它们变成选择器（选中节点 → 右侧「节点属性」面板）。

**选项全部来自 CLI 现问的模型目录（`crate model list --json`），不是 App 里写死的一张表。** 这不是洁癖，是三个必须由数据说话的地方：

- **模型会上下线**。写死列表的后果是用户选了个已经下线的模型，点生成才报错。目录里的 `enabled` 就是为这件事准备的，已下线的不进 picker。本机实测：40 个模型里 13 个能出图，按系列（Seed3.0 / GPT-4 / Qwen / Crate）分组显示。
- **比例选项每个模型各不相同**。`seedream4` 有 `1K`、`seedream45` 没有；`gpt-image-1.5` 只有 `1:1 / 3:2 / 2:3` 三档；`gpt-image-2` 还有 `16:9 4K` 这种"比例+分辨率"的复合值。拿一张统一的常用比例表去喂所有模型，等于把"选项看着能选、提交被拒"做成默认体验。
- **有一类出图模型压根没有 `ratio` 参数**（`t2i_qwen_image`、`t2i_z_image`、`seed3_tt_aoc`、`seededit_v16` 走 `width`/`height`）。对它们必须**不传** `--ratio`，所以尺寸选择器有"该模型按宽高出图，不接受比例预设"这一档，而不是硬塞一个 1:1。

细节：

- **换模型会把比例落到新模型真的接受的值上**：仍在选项里就保留（换模型不该悄悄改构图），否则退到 `1:1`，新模型不吃比例则清空。模型与比例**一次写进撤销栈**——分两次的话 Cmd+Z 会停在"只退回比例、模型还是新的"这种用户从没做过、甚至不合法的中间态。
- **比例与分辨率档在菜单里分组**：`2K` / `4K` 不是宽高比，混在一列里会让人以为选了 2K 还是方图。
- 目录**进程内缓存 + 10 分钟软过期**，外加一个手动刷新按钮（刚在终端 `crate auth login` 完、或刚上线新模型时用）。面板是随选中节点重建的视图，状态放进面板等于每点一个节点就起一个 Node 进程。
- 取目录失败（没装 crate / 没登录）**不弹窗不拦路**：选择器退回只显示当前值 + 一行原因，画布上改字体、连线、归槽都不受影响。
- 模型目录里已经带了完整参数表，顺手喂进 seed 门禁的缓存，省掉一次 `model describe`。
- 比例也有了和 seed 同构的退路：CLI 真拒收 `--ratio` 时去掉重试一次，并 Toast 说明本次用了模型默认尺寸——选择器写着 4:3 却出别的尺寸而不说一声，就是"选项失灵"。
- 只给图像节点：视频节点的 `model` / `ratio` 还没有对应的提交路径，给它一个改了不生效的选择器是负收益。

参数栏为什么不做回卡片上：v2.11.8 把卡片上的「模型 · 比例」那一行删掉是用户明确要求的（"信息量很小"），理由是出图参数属于"要改的时候才关心"。所以入口放在属性面板，卡片高度继续留给正文预览。
