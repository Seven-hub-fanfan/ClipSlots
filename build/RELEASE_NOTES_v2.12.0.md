# ClipSlots v2.12.0 — 画布连线真实化 + 节点即执行单元

> 起因是一句反馈：「我感觉现在让我去用画布很蹩脚」。参考 TapNow 那类 agentic canvas 的做法重做了
> 画布的交互模型。**槽位仍然是唯一的内容源头**，节点仍然只是槽位内容在画布上的一次摆放 —— 变的是
> 节点之间的关系从装饰变成了真的数据流。

## 一、连线真实化

v2.11.x 其实已经有 `parentNodeId`，但它**看不见、也不参与生成**：把文本节点摆在出图节点上游，
连了跟没连一样。这一版换成真实的连线：

- **看得见的连线**：贝塞尔曲线 + 箭头，从上游卡片边缘连到下游，随节点拖动实时跟随
- **从把手拖出连线**：hover 节点右侧出现出口把手，拖到另一个节点即建立连接；拖到空白处直接打开
  「ADD NODE」，新建的节点自动接上
- **连线有角色**：`自动` / `提示词` / `首帧` / `尾帧` / `参考图`。右键连线可改角色、可断开；
  选中连线后按 Delete 也是断开
- **连线可撤销**：连接 / 断开 / 改角色都进操作历史
- **护栏**：自环、重复连接、成环（含 a→b→c→a 这种长链）会被拦下并给出原因；删节点、改绑槽位时
  连线跟着删 / 跟着改
- **老画布自动迁移**：升级后第一次打开，原来的 `parentNodeId` 会变成真实连线（幂等，不会重复迁移）

## 二、连线真的喂进生成

这是上一条的意义所在。生成入参现在先过一遍入边：

- **上游文本拼进提示词**：上游在前（共享的风格设定）、本节点在后（这一张的具体要求）
- **上游产物按角色占位**：显式设过首帧 / 尾帧 / 参考图的连线优先落座，剩下的自动补位；
  多出来的降级成参考图。槽位附件继续补位，同一张图不会被用两次
- **首尾帧与参考图互斥的模型**（如 seedance 系列）依旧尊重模型约束，不会硬凑出一次被拒收的提交
- **上游还没跑完时**报「有 N 个上游节点还没出结果」，不再误报「提示词为空」
- 上游产物文件被手动删掉时算「还没出结果」，不会把一条死路径传给 CLI

## 三、节点即执行单元

以前跑一次图要在「画布节点 → 右侧属性面板 → 右上角生成按钮」之间来回跳。现在 hover 节点即出操作条：

- **生成 / 重跑**就在节点上
- **模型 / 比例**芯片直接切换；视频节点额外有**分辨率 / 时长 / 配音**
- 换模型时比例、分辨率、时长会自动落到新模型接受的档位（与右侧面板同一套规则，不再两处分叉）
- **+ 号**在下游新建节点（取代了原来那个只在单选时出现的浮动 +，同屏不再有两个长得不一样却做同一
  件事的按钮）
- 产物可直接**在访达中显示**
- 有上游时显示入边数量

顶部的「生成」按钮仍然可用（批量跑选中的节点），提示文案不再是「开发中」。

## 四、实现说明

- 新增 Kit 纯逻辑：`CanvasEdge`（模型 + 图算法）、`CanvasEdgeInputs`（角色消歧 → 生成入参）、
  `CanvasEdgeGeometry`（端点 / 贝塞尔 / 箭头 / 命中判定）
- 连线的粗细、箭头、命中容差、把手、操作条全部工作在**屏幕坐标**，不随缩放变化 —— 它们是操作尺度
  而不是画布内容（25% 视图下跟着缩就成了点不中的发丝）
- 拖线状态只活在 View 的 `@State`，不进 `CanvasStore` 的 `@Published`：拖线每帧更新光标，
  发布出去等于每帧重绘所有节点
- 新增 ~46 条 smoke 断言（角色消歧、环检测、迁移幂等、几何退化不产 NaN 等）。全量 32092 条通过
