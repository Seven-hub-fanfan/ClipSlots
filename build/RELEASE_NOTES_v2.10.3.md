## ClipSlots v2.10.3

本版本为稳定性与健壮性专项修复，集中处理并发安全、内存安全、粘贴完整性及 CLI 契约等问题。

### 🔴 P0 严重修复（×2）
- **storageCache 并发锁**：为存储缓存补齐跨线程访问锁，消除数据竞争导致的读写不一致/潜在崩溃。
- **FSEvents 野指针（weak-self）**：文件监听回调改为 weak-self 捕获，修复监听器释放后回调访问悬空指针的崩溃隐患。

### 🟠 P1 重要修复（×7）
- **粘贴内容被截断**：修复长文本/多段内容粘贴时只粘出部分内容的问题，现完整粘贴全部内容。
- **剪贴板还原逻辑**：粘贴流程不再错误还原旧剪贴板，避免覆盖用户当前内容。
- **缩略图渲染挂起**：修复缩略图生成阻塞导致的界面卡顿/挂起。
- **连接缓存并发**：修复连接缓存在并发访问下的竞态问题。
- **CLI 版本查询阻塞主线程**：版本探测移出主线程，避免 GUI 卡顿。
- **CLI 错误码规范**：统一并修正 CLI 错误码返回，保证契约一致性。
- **slots 崩溃**：修复特定 slots 操作路径下的崩溃。

### 🟡 P2 健壮性（全量）
- 游标（cursor）相关健壮性修复。
- 槽位游标角标（badge）显示健壮性修复。
- 其余边界条件与健壮性增强全量纳入。

### 📄 文档 / Skill
- `SKILL.md` 新增 `write-attachment` 文件夹路径约束说明。
- 移除历史 `docs/clipslots-cli-skill-draft.md` 草稿，SKILL.md 成为 Skill 内容的唯一来源。

### 📦 安装
下载下方 `ClipSlots_v2.10.3.dmg`，打开后将 **ClipSlots.app 拖入 Applications 文件夹** 即可完成安装。

> 本 DMG 为 adhoc 签名、未经 Apple 公证（notarize）。若通过浏览器下载，macOS 可能附加 quarantine 属性，可在「系统设置 → 隐私与安全性」中放行，或执行 `xattr -cr /Applications/ClipSlots.app`。
