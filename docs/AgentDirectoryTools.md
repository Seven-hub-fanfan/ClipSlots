# 本地目录工具

目录范围与操作批准分别由用户选择，并在一次 Agent 调用中冻结。已选目录模式提供
`local_list_directory`、`local_read_file`、`local_directory_tree`、`local_write_file`、
`local_batch_write`、`local_organize_files`、`local_undo_directory`、`local_directory_history`。
全部目录只读模式只发布读取工具。完全访问模式可另外提出和消费 shell proposal；
目录范围不构成 shell 的文件或网络沙箱。

目录操作从已授权根的文件描述符遍历，每一层拒绝符号链接。根被删除或被另一目录
替换、原授权移除/重新定位、调用终止或会话改变时，旧访问不能恢复为 Home 或其他目录。
OS 仍可解析的 stale/moved bookmark 可以在保留原目录 ID 的情况下更新路径及书签，
更新目录列表失败时保持原列表并终止本次授权恢复。

批量写入最多16项、每项256KiB、合计1MiB。更新用最近读取的 SHA-256，新建传空值；
手动批准逐项返回决定，批准后逐项重新核对。失败、拒绝或取消不省略对应的结果项。
写入通过新文件交换保留被替换的文件，发现并发冲突时恢复或返回明确的保留路径。
硬链接替换只改目录项，不改外部 inode；普通文件权限保留，新增文件为0600。

目录树最多16层/2000项，不读取文件内容。`complete=false` 和 `truncated` 明确表示
深度/项数预算或不可读子树导致读取不全。`identity` 供整理核对普通文件/目录身份。
整理支持普通文件、二进制大文件及目录，只允许目标不存在时移动；
任一步失败按逆序回滚。回滚遇到并发修改或占用保留现状并逐项报告冲突。

成功操作返回 `undo_id`；撤销时逐项逆序核对，旧 ID 只能消费一次。残余冲突给新 ID，
需要显式核对后重试。生产 ChatModel/目录 Store 将撤销日志保存在 App 私有目录，
绑定会话、项目、授权版本及真实根目录 dev/ino，支持跨调用和重新启动恢复。
OS 移动书签刷新保留授权版本；用户重新授权则更换版本，旧记录不能用于新授权。
日志目录0700、文件0600，不跟随日志目录/文件符号链接；同一日志使用非阻塞文件锁，
并发访问失败会保留记录。最多32条记录/4MiB原始字节，满额拒绝新增，不清理未决撤销。

修改前 fsync 原始字节、身份及操作意图，准备新文件后再记录新 inode，修改后记录提交。
`local_directory_history` 可发现上一调用未返回的 undo_id，核对磁盘但不重做或撤销文件。
崩溃窗口分别显示已应用、未应用、已撤销及 unknown；身份无法证明时保留文件与暂存项，
显式撤销也不会盲删。撤销前先持久消费旧ID，崩溃后通过历史查询发现后继ID。
撤销恢复原字节和普通POSIX权限；连续写入只在原提交身份与恢复字节均证明时延续撤销链。
并发修改、非空目录及被用户编辑的暂存文件逐项保留并返回冲突。
孤立使用 Kit 的访问对象不传 journal context 时仍为调用内撤销；生产路径均传入上下文。

`local_propose_shell` 只保存不可变脚本与目录授权 ID，不执行；提案有效期300秒，
脚本最多64KiB、运行超时1至120秒。`local_execute_proposal` 先消费提案再展示原脚本，
即使自动批准目录写入，也必须单独确认 shell。拒绝、过期、取消不会恢复提案。
输出合计64KiB，返回是否截断、取消、超时与退出码。runner 通过 `posix_spawn` 创建
独立进程组并同时推进非阻塞 stdin/stdout/stderr；取消及超时先 TERM、两秒后 KILL。
进程组退出不是沙箱；自行脱离进程组的恶意进程没有被声明为隔离。

运行本地真实目录/OS书签/后代进程及跨进程撤销/SIGKILL回归：

```bash
bash scripts/test-directory-tools.sh
```

回归只创建隔离临时目录，无 provider 调用；报告包含 Swift 断言及独立 Python 磁盘核验。
持久撤销测试编译真实 App Store 并调用实际工具，父进程在指定边界发送 SIGKILL；
测试用 SPI checkpoint 不由生产 ChatModel 设置。前台批准UX、实体设备和完整来源操作
仍需分别验收，不能从这些进程回归推断通过。
