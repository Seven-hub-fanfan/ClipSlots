# 工作区加载器主题修复：21710815

21710814 的原生加载器将背景固定为黑色，因此浅色模式也显示深色过渡。21710815 根据加载视图的实际 `effectiveAppearance` 同步背景与动画帧，支持应用主题和系统主题切换。

- 浅色模式使用白色背景、深色形变动画。
- 深色模式保留 TapNow 原始黑色背景、白色形变动画。
- 原始 WebP 帧包含不透明黑色背景；浅色适配对整帧执行明暗反转，避免白色背景中出现黑色方框。
- 反转保留原始灰阶渐变与 alpha 值，不重新绘制轮廓；在后台一次解码两套帧。
- 保留 86 帧、每帧 40 ms、3.44 秒循环、64 px 居中和两秒缩放周期。
- 在加载中更换主题只替换颜色与帧集，沿用形变播放起点，缩放动画持续运行。
- 退场后释放两套帧，快速重新切换继续受原有生命周期保护。

原生 Agent 回归新增对全部帧颜色和 alpha 的核验，以及同一加载视图内反复切换深浅主题的运行时检查。实际层渲染核验白色与黑色背景、动画对比度、方形帧与周边背景的一致性，以及两种主题渐变的互补关系。已有滚轮、模型图标、选中与附件、UI 回归仍由原生集成入口验证。

2026-11-07 的本轮原生验证共 496 项，零失败：Agent 集成 361 项、选中与附件 26 项、UI 回归 109 项。深浅模式的运行时截图和同帧图层渲染结果均已检查。

实装复用完整备份时，安装器先预留旧应用的实际大小，再按保护快照预留新增对象和序列化清单的大小。这样避免固定 0.5 GiB 预留误阻止可容纳的后续安装，保留原有备份总量、数量和磁盘剩余空间限制；所有清单和新增对象均在写入前检查额度。

运行入口见 [Agent 原生验证说明](agent-followup-21710814.md)。原生加载器修复只涉及加载视图、对应回归和构建号；核心存储、连接协议、模型与备份重建模块的已验证源码保持一致。安装支持另通过 22 项磁盘保护检查和 3 项备份重建检查。两套主题适配不构成对 TapNow 全场景逐帧相同的声明。
