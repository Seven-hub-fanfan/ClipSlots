# V2.17.2 画布融合版

以 V2.16.5（`c8d19e0`）为界面基底，融合 V2.17.1（`8403c59`）的任务票据、媒体解码和渲染边界。代码位于独立工作树 `ClipSlots-v2.17.2`、分支 `canvas/v2.17.2`。

## 界面与交互

- 保留黑色点阵画布、简洁媒体卡、外置名签、细贝塞尔连线和 44pt 操作胶囊。
- 单选文本、图片、视频节点显示最大 640pt 宽的提示词面板；窗口变窄时收缩，底部放不下时避让。
- 文本正文与生成指令分开保存：卡内双击编辑正文，卡下输入生成指令。图片和视频编辑提示词时保留媒体预览。
- 多选显示整体选区、操作胶囊及汇聚到同一个白色“＋”的引用连线。点击后可创建文本、图片或视频下游，一次连接全部上游，一次撤销/重做包含节点与全部新增连线。
- 支持 Shift 多选、框选、整组拖动、水平/垂直排列、复制内容和加入槽位库。
- 点击空白一次完成编辑保存与取消选择；双击空白添加节点。端口拖线与节点拖动由独立会话锁定；重复连接、自环和环路拒绝连接。
- 空格临时抓手、H 抓手、V 选择、滚轮平移、Cmd+滚轮缩放、适应内容/选区保持可用。

## 生成与数据

- 图片与视频继续通过 Crate CLI 提交、轮询、下载和落库。
- 票据同时绑定项目、节点身份与创建时间。连点不重复提交；归槽迁移身份；删除节点后旧任务不会写到复用槽位；取回已有结果不发新任务。
- 文本生成复用现有 DeepSeek / 自定义兼容接口配置，不开放工具调用。API Key 仍保存在钥匙串。生成指令独立持久化，生成正文可撤销；生成期间手动修改正文会保留用户编辑。
- `.bin` 视频通过保留原扩展名的临时别名供 AVFoundation 解码，修复缩略图、时长和播放识别。
- 保留 V2.16.5 的附件编辑撤销桥、删除项目失败回滚与滚动手势归属。

## 与 TapNow 的边界

这是按参考截图和现有原生实现贴近的版本，不声称全部功能与像素完全一致。

- 文本模型显示实际配置的 DeepSeek/兼容接口模型，不冒充已接入 Gemini；目前只向文本接口发送文字，不解析引用图片或视频的视觉内容。
- 3D 入口保留为不可用状态；没有虚构 3D 生成、语音输入或积分额度。
- 当前 Crate 单节点一次提交一个结果，没有模拟截图中的 4× 批量与积分扣费。
- 自动生成回归使用本地夹具，没有调用收费服务。真实服务仍依赖本机 Crate 登录与 Agent API 配置。
- DMG 为本地 ad-hoc 签名构建，不是 Apple 公证发布。
