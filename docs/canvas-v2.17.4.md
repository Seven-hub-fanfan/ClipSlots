## 217404 · 生成、保存、会话与媒体优化

- 修复审计十类问题：生成前入参校验、多选依赖排序、失败保存重试、附件统一撤销、预览外部刷新、视频实际图位说明、旧任务恢复与本地停止、Agent工具终态与历史/草稿保存、后台媒体LRU，以及入口/错误详情。

- Smoke 32,342项、四主题真实系统鼠标116项、完整画布77项、隔离异常32项和媒体专项88项均通过。生成使用本地夹具；媒体专项使用AppKit事件队列。详细范围见 `optimization-repairs-217404.md`。

## 217403 · 槽位入参与控件命中修订

- 槽位自动连线同时读取正文和全部图片附件，无须槽位先进入生成成功状态。保留连线与附件顺序、过滤断链并去重；支持文件型图片和槽位中已有的生成图。
- 显式“提示词”只传正文，“参考图”传图片，视频首尾帧角色继续优先。图片/视频生成节点仍从自己的产物状态取上游结果；本节点重跑继续排除自身历史生成图。
- 生成输入区显示“槽位 · N 图”和实际参考图总数，可以点击引用返回对应槽位。
- 输出端口上 `.position` 后的悬停修饰产生整块画布大小的透明命中层，挡住低于它的节点工具栏、入参行和扇形预览。移除该层的命中，端口连线继续由原生路由处理。
- 编辑侧 Agent 改为“编辑槽位 / 批量修改 / 槽位整理 / 查找替换”。建议卡填入编辑指令；画布侧继续显示提示词创作与分镜。

## 217402 · Agent 与槽位修订

- 对照用户三段录屏重做 Agent：480pt 侧栏、紧凑会话栏、居中欢迎语、两列建议卡及换一组、一体底部输入。建议填入草稿，不自动发送。
- 回答采用连续排版，保留流式、折叠思考、复制、工具状态和错误重试。翻阅历史时不自动追随每个 token。
- Agent 草稿随会话保存，收起和皮肤切换不丢失；新会话隔离旧流回调；停止时保留部分回答。
- 外观按钮、明暗选项和主题卡都扩展为完整 label 点击区域。
- 槽位外壳、空预览和正文预览统一路由：单击选中/编辑、拖动移动、多选整组移动和一次撤销。有内容的扇形预览显式传递拖动，正文编辑与入参按钮保留独立事件。
- 原生鼠标监听限定在画布边界内，避免把 Agent 按钮点击当作画布空白吞掉；空格抓手仍可从槽位预览区起拖。
- 空槽位移除内嵌白色小卡；节点、添加菜单和生成面板移除黑色重影；扇形文字卡跟随主题。
- 详细参考与截图说明见 `agent-slot-v2.17.4-reference.md`。

## 媒体节点

- 文件粘贴优先识别图片/视频，不再把视频当作 IMAGE，也不被剪贴板附带的预览位图抢占。
- 导入、粘贴、切换项目和产物变更时，卡片采纳实际媒体宽高比。视频计算包含轨道旋转矩阵，媒体画面完整适配卡片。
- 旧文档中仅包含视频参考的方形 IMAGE 节点会修正为 VIDEO，并更新到默认视频模型。
- 已采纳的附件身份持久化；用户随后明确选择的比例不会被无关附件通知覆盖。新媒体替换后重新采纳其尺寸。
- 运行中节点不会被此修复改变类型；生成产物的显示尺寸不会改写用户的生成比例参数。

## 外观

- 编辑区和画布共用「外观」按钮：跟随系统、浅色、深色，以及简洁、多彩主题。
- 画布背景、点阵、文本、菜单、提示词面板、比例面板、工具栏、端口和 Agent 侧栏统一响应主题。
- 简洁主题使用中性色；多彩主题使用紫色文本、青绿色图片、蓝色视频类型色与蓝紫操作色。
- 修复浅色编辑区配深色 Agent 侧栏、白字浅底等混用问题；提亮多彩深色下的功能图标。
- 原生提示词编辑器不再固定深色。切换皮肤重建界面前保存编辑中的文字，保留未按回车的草稿。

## 连线与交互

- 保留 TapNow 参考中的细实线曲线、左右端口、独立点击命中带和无网格吸附拖动。
- 选中连线出现角色与断开工具条，断开可撤销。
- 拖线目标与完成操作尊重浮层遮挡，不能落到面板时连接后方节点。
- 保留双击空白「添加节点」、节点下游「引用生成」两套语义，多选汇聚“＋”继续可用。
