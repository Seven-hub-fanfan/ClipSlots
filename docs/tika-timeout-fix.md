# Tika 新建页面并填写 1–31 序号：超时修复

基线：ClipSlots 2.17.8 / `86194c3`。修复分支：`fix/tika-batch-timeout-2178`。

## 原因与修复

1. 原实现从每轮进程启动开始计时，60秒一到便终止，即使仍在接收推理。现在60秒表示 **stdout空闲时间**，持续输出会续期；每轮另有10分钟硬上限，心跳也不能无限延长。
2. 原工具预算仅8轮，旧提示词要求每次最多一条XML。创建页面及4组占4轮后，只能再填4个序号。默认预算改为48轮，兼容旧Agent；本地工具说明及远端提示词模板支持独立命令合批，依赖操作仍等待上一批结果。
3. 原实现忽略已解析的 `finish` 和服务端错误。现在收到完成或错误信号后给CLI短暂退出宽限，再回收挂起进程并读完管道。服务端错误、异常退出和缺少完成信号的响应不会触发本地XML执行。
4. 超时提示说明实际等待状态，不再直接归因于网络故障。进程启动与取消串行化，保留提前取消的结果，避免丢失等待回调。
