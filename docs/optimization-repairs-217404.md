## 修复内容

| 项目 | 现在的行为 |
| --- | --- |
| 生成入参 | 有自己的提示词也会检查待产、缺失及不兼容上游；本节点缺图会提示；视频不能伪装成图片参数。多选媒体按依赖顺序执行，上游失败时跳过下游。 |
| 保存失败 | 成功落盘后才更新缓存；失败保留内存快照、显示状态并可重试；失败时阻止切项目和退出丢失修改，非当前项目的任务结果同样保留。 |
| 附件撤销 | 入参面板与扇形卡片共用写入事务；删除先暂存字节，落盘成功后记历史；拖动排序松手才记一步。修正原生弹层内部的按钮/拖动控件命中。 |
| 图片预览 | 文件型图片、外置存储、路径及内嵌字节共用解析；缓存识别文件修改时间、大小与身份；同路径覆盖、缺失后恢复会刷新。 |
| 视频入参说明 | 输入区展示实际首帧、尾帧、参考数量和未使用数量；与提交共用模型规则。仅传参考图时不再误触发首尾帧互斥排除。悬停说明互斥/上限及点击连线调整角色。目录未知时保留图位。 |
| 任务恢复/停止 | 未完成任务主按钮为“继续查询”，单独保留“重新生成”。停止结束本地跟踪，保留远端 taskId；提交期间请求停止会等待身份回执，避免丢失任务。 |
| Agent 停止 | 补齐未完成工具调用的结果配对，工具行显示“已停止 · 结果未知”；晚到回调不会重新写入对话。不会把停止本地跟踪误报为撤销工具操作。 |
| Agent 会话 | 编辑/画布独立存储最近30条历史及当前草稿，新建对话归档当前内容；会话菜单可恢复，退出时检查保存，读取失败保留旧文件副本。 |
| 媒体读取 | 尺寸/时长移至后台串行队列；512项LRU逐项淘汰，按文件来源与版本复用。布局写回核验项目/节点/附件身份，保持原始媒体比例及用户后续显式比例。 |
| 入口与错误 | 未接入项持续标注状态；文本说明统一为生图Prompt优化；Agent使用运行版本；生成错误可展开完整原因、选中文本及复制诊断信息。切皮肤前提交各窗口编辑器，修复外观弹层打开时漏存草稿。 |
