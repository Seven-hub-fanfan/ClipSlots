# 模型工作区（v2.17.98）

顶部“模型”入口包含测评、排行榜、配置中心和 AI 日报。保留原生深浅主题及顶部导航动画。

## 使用

1. 在配置中心添加完整 API 请求地址、模型标识、输出类型和接口契约。密钥进入 macOS 钥匙串；导出的题库、结果集及默认参数不包含密钥。
2. 分别设置 Agent LLM、出题 LLM、画布图像、视频和音频的默认模型。Agent 和出题用途仅接收 Chat Completions API。内部产品 CLI 独立成合集，Crate / ByteArtist 可发现并加入能力目录；Tika 沿用 Agent 环境配置。
3. 绑定槽位组建立题库。题干及参考附件读取权威槽位，保存题目同步正文、保留原附件；槽位版本发生冲突时显示新旧正文，选择保留内容后再次核验版本。题库配置可追加或解绑组，解绑保留槽位内容。
4. 出题 LLM 返回草稿，审核后保存到绑定组的空槽；组满时保留未保存草稿。可选择全部题目或子集，一次对比 1–14 个模型，实际请求并发最多 4，并遵守各模型并发限制。
5. 结果集支持文本与媒体预览、人工评分、导出及保存到空槽位。六维排行榜使用实际评分，按题目集合、适用维度及评分来源分榜，不把缺失或不适用维度算作零分。LLM、图像、视频及音频可分别查看。
6. 画布图像/视频节点的生成来源菜单可选择 API 或默认 API；音频编辑器提供统一目录选择。任务冻结所用配置，切换目录中的模型不会修改已提交任务的查询身份。
7. AI 日报按公开 RSS / Atom 原文发布时间排序。进入页面检查每日刷新，也可主动刷新、搜索及编辑来源；部分来源失败时保留缓存。发布时间未知的资讯不标为今日，显示的摘要来自新闻源。

## API 契约

- Chat Completions：单次 `messages` 请求，测评与出题无工具执行；声明图像输入能力后可发送本地 PNG/JPEG/WebP 参考。
- Images Generations：读取 `data[].url` 或 `data[].b64_json`。
- 异步媒体：配置提交任务 ID、查询状态、产物 URL 的点号字段路径及成功/失败状态；查询地址包含 `{id}`。参考输入字段可按服务文档配置为接收 data URL 数组的字段。
- 不猜测服务字段。接口未声明的本地参考输入会阻止提交，避免静默忽略参考素材。

服务兼容性需要使用者提供真实地址、接口契约与密钥。异步视频/音频接口的任意服务差异不能由默认参数自动推断。

## 数据与恢复

配置、题库、结果集和新闻缓存保存至数据根目录下 `models/workspace.json`，采用独立 actor、独立锁和带版本检查的原子保存。读取失败停止写入；没有变化的启动保持文件原字节。

每次测评复制参考素材形成输入快照，保留题库和模型配置版本。已确认远端任务 ID 立即持久化；中断后继续查询原任务。网络中断、5xx 或无法确认的 POST 返回标记为“提交未知”，不自动重提。取消停止本地新请求/查询，远端可能仍在运行。媒体下载或槽位保存失败可保留原任务与结果集。
