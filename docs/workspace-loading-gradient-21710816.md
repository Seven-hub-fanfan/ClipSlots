# 工作区加载器灰阶渐变修复：21710816

21710815 的浅色加载层采用纯白背景和黑色图形，偏离用户提供的参考截图。21710816 根据截图采样，使用 `#ececec` 背景及 `#444444` 图形，降低浅色过渡的对比度。

原始 WebP 帧整体进行灰阶映射：输入黑色对应 236，输入白色对应 68，中间灰阶按线性比例保留。图形帧背景与覆盖层使用相同颜色，避免淡入淡出时出现方形接缝。全部 86 帧保留 alpha，深色帧使用原始资源。

原有 64 px 尺寸、40 ms 帧时长、3.44 秒形变循环、两秒缩放周期，以及覆盖层和图形的淡入淡出曲线保持不变。加载中切换主题仍沿用形变与缩放时钟。

对应原生回归覆盖所有帧的参考颜色端点、中间灰阶、alpha、实际图层颜色及接缝，并重复检查主题切换。运行时淡出采样同时覆盖 AppKit 与 SwiftUI 宿主及快速结束场景。参考截图只能支持颜色核对；本次结果不代表 TapNow 所有场景的逐帧动画等同。

最终验证：497 项原生检查零失败，包含 Agent 集成 362 项、选中与附件 26 项、UI 回归 109 项；实际窗口另通过 20 项淡出和快速结束场景。GUI、CLI、MCP 的 Release 构建及候选包签名核验通过。安装支持的 22 项磁盘保护和 3 项备份检查通过，核心 43,843 项沿用已验证源码哈希对应的既有结果。

离屏图层截图使用线性采样，对应 CALayer 的默认采样方式。CGContext 默认缩小插值会在轮廓边缘产生过冲，浅色范围扩展到 61–243；线性采样得到正确的 68–236 范围，灰阶映射最大误差 2，最近邻对照误差 0。帧像素和实际窗口检查独立于这项离屏采样核验。

版本 21710816 的构建、验证和安装记录保存在 `deliverables/agent-api-motion-demos-20261105/gray-gradient-21710816/`。参见 [上一版主题修复](workspace-loading-theme-21710815.md) 和 [原生验证入口](agent-followup-21710814.md)。
