# 飞书工具连接与弹窗关闭修复

构建 21710821。默认工具服务改为 `https://mcp.tapnow.media/api/agent-gateway/mcp/general/mcp`，授权方为 `https://oauth.tapnow.media`。先核验受保护资源元数据、issuer 与 PKCE S256 契约，再开始原生授权。显式海外绑定仍使用其对应域名，凭据按账号、资源和 issuer 绑定；旧钥匙串记录保留。

原先三个视图各自为同一连接状态呈现 SwiftUI sheet，关闭仅调用环境 dismiss。改为共享单一呈现权的 AppKit 子窗口。关闭按钮、Esc、⌘W、宿主关闭和视图拆卸统一取消请求、清理状态与窗口，不进入应用级 modal loop。

授权任务在发现、浏览器回调和 token 交换阶段均支持取消。continuation 恰好完成一次，晚到回调不能恢复已取消任务，也不能在账号或连接改变后写入授权或工具绑定。安装保留已有加载动画与虚化过渡。

回归使用隔离 HTTP、内存凭据及真实 AppKit 窗口，不自动授予第三方账号权限。实际飞书连接仍需用户在授权页面完成同意。

实装版已验证关闭、Esc、重开，以及等待授权时 ⌘Q 正常退出和重新启动。为避开模型钥匙串提示，UI 检查使用临时 NSArgumentDomain 后端选项，未执行模型请求；保存的模型配置哈希不变，随后恢复正常启动。国内元数据接口返回 200，原生授权请求已发起；本机 SafariLaunchAgent 因窗口服务器 bootstrap 权限错误（1100）未打开浏览器登录页，真实账号授权与云端工具调用尚未验证。
