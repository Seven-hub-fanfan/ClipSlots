## 本版实施范围

1. 节点下方的生成面板整合提示词、模型参数、入参概况和运行入口；编辑提示词时保留媒体可见。属性面板按需打开。
2. 点阵背景、简洁媒体卡、稳定的选中操作条；悬浮面板避让窗口边缘和槽位库，窄窗可用。
3. 空格临时抓手、V/H/N、全选、适应选区/内容；快捷键让位文本编辑与模态预览。
4. 输出/输入端口与连线端点一致；扩大端口命中范围，合法目标吸附，空白落线创建下游。
5. 避免鼠标移动更新根视图；节点内容渲染与视口变换解耦；屏外节点裁剪；按实际变化发布任务状态。
6. 生成任务绑定项目与节点创建身份，防止删除/重建/切项目/入库后旧任务写错；结果下载落盘、支持恢复查询，避免重复扣费。
7. 修复连线删除后重启复活、选择互斥、历史面板撤销与私有内容对账等已发现的功能一致性问题。

## 实际实现

- `CanvasNodeComposer`：单选媒体节点后显示提示词、模型、比例、视频参数、参考附件、运行和产物动作。文本编辑使用独立状态；原媒体保持可见；面板不跟随画布字号缩放。属性面板通过右上按钮/右键显式打开。
- `CanvasRenderBoundary`：节点内容与选中面板按内容键重算，视口仅更新位置和缩放；跨过文字显示阈值才重新构建文字。屏外节点按 240pt 余量裁剪，拖拽和编辑节点保留。
- 点阵背景；端口扩大到 32pt 命中区；入口 24pt 吸附；输出右侧、输入左侧不跳边。选中操作优先于悬停，避免操作对象突然换人。
- 空格临时抓手、V/H、N、Cmd+A、Shift+1/2。全屏预览屏蔽画布删除；可编辑 NSTextView 保留自己的键盘语义。适应内容给生成面板留出垂直空间。
- `CanvasGenerationTicket` 和 `CanvasStore` 共同保存执行归属：项目 + 节点创建时间 + 执行 UUID。切项目后更新原文档，归槽后迁移任务，删除节点/项目撤销任务归属，迟到结果不写入复用槽位。
- 图片和视频共用提交/查询/下载/写回流程。任务 ID 提交后落盘；“取回结果”只查已有任务；同任务结果幂等。下载走 URLSession.download，附件通过现有文件克隆摄取，不把整个视频读成主线程 Data。
- 修复 `.bin` 视频无法预览：用保留原视频扩展名的临时软链接供 AVFoundation 读取，不复制视频字节；首帧、时长、尺寸和全屏播放使用一致的入口。
- 修复缩略图请求合并后遗漏其他订阅者回调；修复连线断开后迁移复活、节点/边选择互斥、历史恢复私有槽位内容、Esc 取消后失焦误保存。画布保存队列保序，避免旧的防抖快照覆盖切项目前的新快照。

## 边界与后续

- TapNow 仅核对其本机安装包自带的参考画布图，未取得桌面辅助访问，不能宣称完整逐像素/逐手势复刻。
- 没有提交真实计费任务；线上模型可用性、排队时延、服务端错误与长视频压力需后续真实使用验证。
- 生成附件最终摄取保留存储队列的同步确认，以保证临时文件寿命与当前组写序；磁盘锁竞争下仍可能短暂停顿。批量生成、任务取消 API、DAG 自动调度未新增。
- 极小窗口可能受现有整 App 最小尺寸约束；面板可在当前可用画布区域内避让，超大缩放时仍可能覆盖媒体的一部分。
- 本分支基于 `0716810`；未合并另一个 agent 的改动，未替换日常 `/Applications/ClipSlots.app`。
- 本地打包使用 ad-hoc 签名，未做 Apple 公证。仓库中的旧 `sync-skill.sh`/CLI 草稿路径不存在，打包沿用当前 `skills/clipslots-manager/SKILL.md` 并校验包内存在。
