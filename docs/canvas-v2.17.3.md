# V2.17.3 · 节点构图与生图提示词

基于已安装的 V2.17.2 构建 217202 继续修订，独立工作树 `ClipSlots-v2.17.3`、分支 `canvas/v2.17.3`。版本 2.17.3，构建号 217301。

## 节点与参数

- 对照 TapNow 录屏 41–54 秒：选择宽高比后，图片/视频卡片立即变成对应构图；保留短边长度和中心位置，端口、连线和提示词面板跟随真实边界。
- 新建文本为方卡、图片为对应比例、视频默认为 16:9。既有节点保留尺寸，选择参数后按比例调整。
- 比例使用缩略构图网格选择器，选项来自实际 Crate 模型目录，支持 `16:9 4K` 等复合档位，不添加后台不支持的参数。
- 比例与尺寸作为同一条历史操作保存，可一次撤销/重做，重新打开项目仍保留。
- 宽节点的提示词面板适当加宽；高竖图在上下都放不下时优先利用侧边空白。引用来源显示为可点击的类型图标。

## DeepSeek 的作用

截图里出现的是 SVG 源码，并非字符编码损坏。旧指令允许模型自由“创作内容”，又直接把返回值写入正文。

- 文本节点现在明确承担生图 prompt 优化：保留输入意图，补足主体、构图、景别、光线、材质和风格，默认产出中文自然语言。
- 原始需求与优化结果分别保存，结果可编辑、复制、撤销，并通过连线供图片节点引用。
- 不提供工具或生图调用；混选文本与媒体批量运行时先完成提示词优化，媒体需再显式运行。
- SVG、HTML、代码、JSON、损坏字符或空结果不会覆盖正文。异常格式最多进行一次文本纠正请求；仍无效则保留原文并提示失败。
- 用户未指定画幅时不让文本模型附加数字比例，以免与图片节点参数冲突。
- 实际模型与 API Key 仍使用现有设置，密钥仅由 Keychain 读取。
