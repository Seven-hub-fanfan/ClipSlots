## 候选与使用范围

运行 `python3 scripts/package_agent_loop_candidate.py` 生成 `build/agent-loop-candidate/ClipSlots Agent Loop.app`。候选构建号 `21781101`，基于 217811；这是本地调试候选，不是正式发布。

双击候选 `.app` 时，原生启动器将数据固定到同级 `CandidateData/`，配置固定到其中 `config.toml`；应用偏好使用独立 bundle ID。没有复制真实素材、替换 `/Applications/ClipSlots.app`、安装 CLI 或提交推送。

体验流程：添加文字节点 → 选中 1～3 节点 → 右侧“引用选中素材” → 输入要求并发送 → 选中一个回填目标 → 回答下方“预览并填入选中节点” → 核对原文与新文 → 确认应用 → 定位或撤销。候选默认空数据；真实模型发送与媒体生成未代用户执行。

限制：首期只回填单节点文字，不包含批量节点创建/成组写入、媒体生成、费用估算、自动恢复远端任务。关闭预览后可通过画布历史撤销；切项目或重启会按原画布行为清空本次内存撤销栈，已保存正文不回滚。旧版记录可从侧栏会话菜单查看。
